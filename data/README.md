# Local operating data

Wealth OS stores user-entered state in `data/state.json` by default. The actual state file is gitignored because it may contain sensitive personal or financial information.

Example shape:

```json
{
  "goals": ["Build durable ownership and cash flow"],
  "priorities": [],
  "deals": [],
  "wealth_snapshot": {},
  "habits": {},
  "relationships": [],
  "notes": []
}
```
